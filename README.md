# Northstar launchers

Public SVG launchers generated by Northstar. Names and URLs in this repository are public, and jsDelivr may retain cached files. Each launcher loads its current destination from the Northstar server. Deleting a link on Northstar disables that destination for future visits.

These files contain no account passwords, session cookies, or GitHub credentials.
